使用前请先确认

这些是软件正常工作的必要条件。

  • Windows + macOS已打包为桌面客户端，无需安装 Python。

筛选方式

三类条件，缩小创作者范围

关键词决定内容方向，国家地区限定目标市场，订阅量帮助匹配创作者量级。

  1. 关键词

    输入品牌名、竞品词或行业词，从相关视频中找到频道。

  2. 国家地区

    按频道公开展示的国家地区进行过滤，也可留空不限制。

  3. 订阅量范围

    设置最小值与最大值，从长尾创作者到大型频道按需筛选。

数据从哪里来

基础数据与补充信息来自不同阶段。页面不将二者混为“全部官方 API”。

API

搜索相关视频

通过 YouTube Data API v3 按关键词获取视频与频道线索。

FILTER

去重并筛选频道

合并重复频道，根据国家地区与订阅量条件过滤。

OPTIONAL

补充公开页面信息

开启补抓后，尝试从频道 About 页补充公开社媒链接与联系信息。

CSV

边采集边保存

每获得一条有效结果即写入 CSV，日志同步记录运行过程。

结果边界：部分频道不公开国家地区、社媒链接或邮箱；API 配额、页面可访问性与平台规则也会影响采集数量。

CSV 输出

从频道线索到公开联系入口

导出结果可用于频道建库、海外营销调研和后续人工筛选。请以当前版本实际导出字段为准。

频道基础信息

频道名称、ID、频道链接、国家地区、订阅量、视频总数、总播放量和注册日期。

常见问题

这些问题会直接影响使用结果，建议购买前阅读。

是否需要安装 Python？

不需要。软件已打包为 Windows 和 macOS 桌面客户端，下载对应版本后解压运行。

为什么要自己申请 API Key？

频道搜索和基础数据依赖 YouTube Data API v3。每个 Key 的配额由 Google 控制，任务量较大时可能耗尽当日配额。 查看申请教程

v2.1 的多 API Key 轮换有什么作用？

当你配置多个有效 Key 时，软件可在配额切换场景中自动轮换。它不会增加单个 Key 的官方配额。

如何保管 API Key？

API Key 属于敏感凭据，请勿上传到 GitHub、发送给他人或放入公开文档。建议定期查看 Google Cloud 中的调用量，发现异常后及时更换或撤销。

为什么有些频道没有邮箱或社媒链接？

只有频道主动公开展示，且 About 页可正常访问时，补抓模式才可能获得这些信息。补抓并不保证每个频道都有结果。

为什么实际结果少于预期？

常见原因包括关键词结果有限、筛选条件过窄、频道未公开国家地区、API 配额不足或页面暂时不可访问。

中断后已采集数据会丢失吗？

软件按条写入 CSV，已经保存的数据不会因后续网络异常或任务中断而被整体丢失。建议仍在重要任务后及时备份结果。

GitHub 仓库是否包含源代码？

不包含。该仓库用于产品说明、版本发布和客户端下载，软件为商业授权产品，不以开源项目形式发布。
