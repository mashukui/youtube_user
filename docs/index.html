❓ 常见问题 ❓ FAQ

🟢 是否需要安装 Python？
不需要。软件已打包为桌面客户端，下载对应系统版本后即可运行。
🟢 Do I need to install Python?
No. The software is packaged as a standalone desktop app — just download and run.
🟢 为什么要自己申请 API Key？
软件调用 YouTube 官方 API（非爬虫模拟），每个用户需要用自己 Google 账号申请 API Key，免费额度每天 10,000 单位，日常采集完全够用。👉 开通教程
🟢 Why do I need my own API key?
The tool uses YouTube's official API (not web scraping). Each user needs to apply for an API key with their Google account. Free quota is 10,000 units/day — plenty for daily use. 👉 Setup guide
🟢 使用官方 API 有反爬风险吗？
没有。软件 v2.0 已升级为调用 YouTube Data API v3 官方接口，合法合规，无反爬封号风险。
🟢 Is there any anti-scraping risk?
None. v2.0 uses the official YouTube Data API v3 — fully compliant, no risk of account bans.
🟢 采集中断后数据会丢失吗？
不会。软件每采集一条数据就保存一次 CSV，即使网络异常或程序中断，已采集的数据不会丢失。
🟢 Will I lose data if crawling is interrupted?
No. Each entry is saved immediately to CSV — network issues or crashes won't wipe collected data.
